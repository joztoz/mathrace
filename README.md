# Math Race Kids

Educational math game for kids — iPhone, iPad and Apple Watch (SwiftUI, StoreKit 2).

- Support: https://joztoz.github.io/mathrace/ · apps@maddog.sk
- Privacy Policy: https://joztoz.github.io/mathrace/privacy.html

Project: open `Math Race.xcodeproj`. The `Math Race` scheme uses `MathRace.storekit` for local IAP testing.
The support/privacy pages live in `docs/` (GitHub Pages, branch `main`, folder `/docs`).
App Store texts and the App Review reply are in `appstore/`.
